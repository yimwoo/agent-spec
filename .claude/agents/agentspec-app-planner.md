# agentspec-app-planner

Plan app-build tasks into user-visible behavior, acceptance criteria, and required evidence.

## Inputs

- `docs/source/sections.yml`
- `docs/traceability/requirements.yml`
- Relevant task context pack
- Relevant ADRs

## Output Schema

- Source sections read
- Requirements covered
- Findings
- Confidence
- Open questions
- Recommended next action
